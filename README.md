# laminas-crypt

## Abandoned
This package is **abandoned** and will receive no further development!

See the Technical Steering Committee [meeting minutes](https://github.com/laminas/technical-steering-committee/blob/main/meetings/minutes/2023-11-06-TSC-Minutes.md#abandon-laminas-crypt)

This is a fork of [laminas/laminas-crypt](https://github.com/laminas/laminas-crypt). It has not and will not receive any feature changes, but compatibility with PHP 8.4 and PHP 8.5 was checked.
